# Modus - Minimalist Digital Lifestyle Blog

A modern, responsive web blog dedicated to exploring minimalist living and technology. **Modus** is a platform created by Sarah Kennedy to share insights on how to lead a balanced digital lifestyle in today's tech-driven world.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern Navigation**: Fixed navbar with hamburger menu for mobile responsiveness
- **Multiple Pages**:
  - Home page with hero section and featured articles
  - Lifestyle section for living tips
  - Tech articles for technology insights
  - About page with creator bio
- **Visual Storytelling**: Beautiful mosaic grid layouts with high-quality images
- **Interactive Elements**: Smooth transitions and engaging user experience

## 🎨 Design Highlights

- **Minimalist Aesthetic**: Clean, simple design philosophy that emphasizes content
- **Typography**: Uses Playfair Display font for elegant headings
- **Color Scheme**: Dark navbar (#2a2a2a) with light backgrounds for contrast
- **Layout**: Grid-based layouts for organized content presentation
- **Mobile-First**: Responsive design with hamburger menu for smaller screens

## 💻 Technologies Used

- **HTML5**: Semantic markup for content structure
- **CSS3**: Advanced styling with media queries for responsiveness
- **JavaScript**: Interactive features including mobile menu toggle
- **Font Awesome Icons**: Icons for enhanced visual design (v6.5.1)
- **Google Fonts**: Playfair Display for typography

## 🔧 Customization

### Update Navigation

Edit the navbar links in the HTML files to add or remove pages:

```html
<ul class="nav-menu">
  <li><a href="index.html" class="nav-link">Home</a></li>
  <li><a href="lifestyle.html" class="nav-link">Lifestyle</a></li>
  <!-- Add more links here -->
</ul>
```

### Modify Styles

All CSS is located in `Css/style.css`. Update colors, fonts, and spacing by editing CSS variables and selectors.

### Add New Images

Place images in the appropriate folder under `images/` and reference them in the HTML files.
